# 捷運任我行

捷運任我行是一個以台北捷運路網為主題的隨機選站小工具。當你不知道今天想去哪裡走走時，按一下按鈕，應用會在捷運圖上快速穿梭並抽出一個目的地，讓下一站交給緣分決定。

## 功能特色

- 以互動式捷運路線圖呈現台北捷運主要路線與站點。
- 隨機抽出台北捷運站作為今日目的地。
- 抽選過程會在地圖與結果卡片中即時動畫切換。
- 支援站點 hover / focus 顯示中文站名、英文站名與所屬路線。
- 以路線顏色與標籤標示淡水信義線、板南線、松山新店線、中和新蘆線、文湖線與環狀線。

## 技術

- Nuxt
- Vue
- TypeScript
- Nuxt UI

## 開發

安裝相依套件：

```bash
pnpm install
```

啟動開發伺服器：

```bash
pnpm dev
```

建立正式版：

```bash
pnpm build
```

本機預覽正式版：

```bash
pnpm preview
```
